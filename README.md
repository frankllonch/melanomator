# 🩺 Melanoma Classifier

An AI-powered skin lesion classification system that predicts whether an image is Benign or Malignant.
Built with PyTorch, Streamlit, and Plotly, this project aims to provide a fast, explainable, and accessible diagnostic prototype — paving the way toward a future mobile health app.

Upload any skin lesion image to get a prediction, probability score, and Grad-CAM heatmap visualization.

# 🧠 Project Overview

### The project consists of:
	•	A Custom CNN model and ResNet18 baseline for melanoma classification.
	•	A Streamlit web app for real-time predictions and visualization.
	•	A Grad-CAM module for model explainability.
	•	A presentation summarizing model results, metrics, and future vision.

# 📊 Data Used

The models were trained and validated on a balanced melanoma dataset (50% benign / 50% malignant).
Images were resized to 224×224×3 and normalized for input consistency.
